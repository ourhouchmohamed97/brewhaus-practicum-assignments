# Wanderlust Destinations (React + Vite + Tailwind)

Assignment 2: Assignment 1's travel landing page rebuilt with React, Vite and Tailwind CSS v3 (plain JavaScript).

## Live Demo

[Click to view!](https://brewhaus-practicum-assignments-taupe.vercel.app/)

## Run
```bash
npm install
npm run dev
npm run build
```

## Structure
```
src/
  data/       tours.js, reviews.js        <- data arrays
  components/ Header, Hero, TourGrid, TourCard, QuantityStepper,
              Testimonials, QuoteSection, Footer, Container, Icons
  App.jsx     composes the page
```
